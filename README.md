## Architecture & Technology Stack

- **Framework:** [Astro](https://astro.build/) (Static Site Generation, 0 KB client JS by default)
- **Documentation Engine:** [Starlight](https://starlight.astro.build/) (Multi-tier sidebar, breadcrumbs, table of contents)
- **Search Engine:** [Pagefind](https://pagefind.app/) (Offline client-side instant search, zero external APIs)
- **Styling:** Custom Obsidian Slate (`#0B0F17`) and Vibrant Emerald (`#10B981` / `#34D399`) design system
- **SEO & AI Bot Files:**
  - `robots.txt` — Comprehensive crawler and AI agent permissions (GPTBot, ClaudeBot, Gemini, Perplexity)
  - `llms.txt` — Standard LLM discovery file specifying extension capabilities, author profile, and architecture
  - `llms-full.txt` — Complete technical knowledge base for LLMs, RAG pipelines, and automated agent ingestion
  - `humans.txt` — Project credits recognizing Utkarsh Kumar as creator and lead engineer
  - `.well-known/security.txt` — Security disclosure policy
  - `sitemap.xml` / `sitemap-index.xml` — Automated XML sitemap generated by `@astrojs/sitemap`
  - JSON-LD Structured Data — Schema.org `SoftwareApplication`, `Person`, and `WebSite`
